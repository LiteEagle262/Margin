# ScrapeFlow Website

Marketing homepage for the ScrapeFlow Chrome extension.

## Stack

- Next.js 16 (App Router)
- React 19
- MUI 9

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Configuration

Edit `src/lib/constants.ts` to update:

- `GITHUB_URL` — repository link
- `CHROME_STORE_URL` — Chrome Web Store listing
- `PLANS` — subscription tiers and pricing copy
